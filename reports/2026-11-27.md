# Self-Hosting Weekly — November 27, 2026

**Edition #14 · 25 projects · 20 discoveries + 5 notable updates**

This week is about owning the small pieces of everyday life: books, fitness records, household paperwork, travel plans, website comments and personal finances. BookOrbit, Papra and Remark42 are particularly compelling, while FreshRSS and 2FAuth deserve attention for security fixes.

Discovery candidates were checked against GitHub repository activity searches and upstream READMEs; newly featured does not mean newly launched. Specific release claims are based on upstream release records. Images are linked from upstream READMEs, not copied into this repository; binary rendering has not been independently tested. Check architecture support, licensing and backup instructions before deploying.

## New & Interesting

### 1. OpenSign — Document signing

**Project:** [GitHub](https://github.com/OpenSignLabs/OpenSign) · [Releases](https://github.com/OpenSignLabs/OpenSign/releases)

![OpenSign — upstream project visual](https://github.com/user-attachments/assets/b38d54cd-abd1-40d6-87ff-b9ef32e0cb18)

OpenSign handles signature requests, templates and document completion from a self-hosted interface. Its v3.2.0 release on November 20 added folder search and improved email-delivery tracking. It is worth evaluating against DocuSign for routine agreements, with a separate review of legal and audit requirements.

### 2. wger — Fitness tracking

**Project:** [GitHub](https://github.com/wger-project/wger) · [Releases](https://github.com/wger-project/wger/releases)

![wger — upstream project visual](https://raw.githubusercontent.com/wger-project/wger/master/wger/core/static/images/logos/logo.png)

This established fitness manager combines workout routines, progression rules, nutrition and body measurements. Mobile clients make it more practical than a browser-only exercise log. It could replace a combination of workout and calorie-tracking subscriptions, although food database coverage varies.

### 3. SparkyFitness — Personal health dashboard

**Project:** [GitHub](https://github.com/CodeWithCJ/SparkyFitness) · [Releases](https://github.com/CodeWithCJ/SparkyFitness/releases)

![SparkyFitness — upstream project visual](https://github.com/user-attachments/assets/d8b09f48-cb4d-41a6-b678-ac93e551f257)

SparkyFitness brings nutrition, exercise and body metrics together in a privacy-oriented application. Its broad scope makes it an interesting alternative to maintaining several separate fitness accounts. Test the mobile workflow and backup process before entrusting it with a long-term health history.

### 4. BookOrbit — Digital library

**Project:** [GitHub](https://github.com/bookorbit/bookorbit) · [Releases](https://github.com/bookorbit/bookorbit/releases)

![BookOrbit — upstream project visual](https://raw.githubusercontent.com/bookorbit/bookorbit/HEAD/docs/images/dashboard-overview.png)

BookOrbit serves ebooks, PDFs, comics and audiobooks from a personal library. Version 3.10.0 on November 24 introduced grouping different editions of the same book while preserving separate reading progress. That is especially useful for households with both audio and ebook copies, and makes it a credible alternative to fragmented commercial reading libraries.

### 5. ezBookkeeping — Personal finance

**Project:** [GitHub](https://github.com/mayswind/ezbookkeeping) · [Releases](https://github.com/mayswind/ezbookkeeping/releases)

![ezBookkeeping — upstream project visual](https://raw.githubusercontent.com/wiki/mayswind/ezbookkeeping/img/desktop/en.png)

This MIT-licensed finance application emphasizes transaction entry, imports and everyday spending analysis. Its compact approach is attractive if you want a personal ledger rather than a full accounting system. It could replace a budgeting subscription for users comfortable importing their own statements.

### 6. Papra — Document archive

**Project:** [GitHub](https://github.com/papra-hq/papra) · [Releases](https://github.com/papra-hq/papra/releases)

![Papra — upstream project visual](https://raw.githubusercontent.com/papra-hq/papra/HEAD/.github/papra-screenshot.png)

Papra provides a deliberately simple archive for receipts, warranties and other documents worth retaining. Its documented Docker installation and restrained interface make it an appealing alternative to a sprawling document management suite. Try it as a searchable household filing cabinet before migrating an existing archive.

### 7. Remark42 — Website comments

**Project:** [GitHub](https://github.com/umputun/remark42) · [Releases](https://github.com/umputun/remark42/releases)

![Remark42 — upstream project visual](https://raw.githubusercontent.com/umputun/remark42/HEAD/screenshots/comments.png)

Remark42 is a mature lightweight comment engine that can be embedded in blogs and static websites. It supports moderation, threaded discussions and several authentication methods without relying on advertising-based comment services. Independent publishers looking to replace Disqus or a paid comment widget should give it a look.

### 8. MediaCMS — Video publishing

**Project:** [GitHub](https://github.com/mediacms-io/mediacms) · [Releases](https://github.com/mediacms-io/mediacms/releases)

![MediaCMS — upstream project visual](https://raw.githubusercontent.com/mediacms-io/mediacms/main/docs/images/index.jpg)

MediaCMS is an open-source video and media publishing system with a browsable library and embedded playback. It is a useful alternative to paying for a private video portal or relying entirely on public video platforms. Transcoding is resource-intensive, so a NAS or stronger server is a better starting point than a small Pi for busy libraries.

### 9. WhoDB — Database workspace

**Project:** [GitHub](https://github.com/clidey/whodb) · [Releases](https://github.com/clidey/whodb/releases)

![WhoDB — upstream project visual](https://raw.githubusercontent.com/clidey/whodb/main/docs/images/light/09-data-view-users-table.png)

WhoDB offers a browser workspace for browsing database tables, editing rows and exploring schemas. Its lightweight presentation makes it a useful alternative to installing a desktop database client on every machine. Keep the interface private and use restricted database credentials, especially for production systems.

### 10. Grimmory — Reading library

**Project:** [GitHub](https://github.com/grimmory-tools/grimmory) · [Releases](https://github.com/grimmory-tools/grimmory/releases)

![Grimmory — upstream project visual](https://raw.githubusercontent.com/grimmory-tools/grimmory/HEAD/assets/logo-with-text-light.svg)

Grimmory is a self-hosted digital library aimed at readers who want more than a folder of books. It belongs on the shortlist alongside BookOrbit for evaluating library organization and reading workflows. Compare import compatibility and mobile reading support with your existing collection before committing to either.

### 11. Hi.Events — Event ticketing

**Project:** [GitHub](https://github.com/HiEventsDev/Hi.Events) · [Releases](https://github.com/HiEventsDev/Hi.Events/releases)

![Hi.Events — upstream project visual](https://raw.githubusercontent.com/HiEventsDev/Hi.Events/HEAD/.github/assets/readme-showcase.png)

Hi.Events provides event pages, ticket sales and event management under your own brand. Its established release history and polished organizer interface make it a plausible Eventbrite alternative for workshops and community events. Self-hosting removes the platform subscription from the equation, but payment processing and operational costs still apply.

### 12. AdventureLog — Travel planning

**Project:** [GitHub](https://github.com/seanmorley15/AdventureLog) · [Releases](https://github.com/seanmorley15/AdventureLog/releases)

![AdventureLog — upstream project visual](https://raw.githubusercontent.com/seanmorley15/AdventureLog/HEAD/brand/screenshots/map-light.webp)

AdventureLog combines a travel diary, visited-location map and trip itinerary planner. The interface makes it useful both before a trip and as a permanent record afterward. It is a compelling alternative to a paid travel journal, particularly for families that want to keep their location history private.

### 13. Yamtrack — Media tracking

**Project:** [GitHub](https://github.com/FuzzyGrim/Yamtrack) · [Releases](https://github.com/FuzzyGrim/Yamtrack/releases)

![Yamtrack — upstream project visual](https://cdn.fuzzygrim.com/file/fuzzygrim/yamtrack/homepage.png?v2)

Yamtrack records media consumption and organizes it into lists, calendars and statistics. It is a practical companion to a media server rather than a replacement for playback software. People juggling several commercial watchlist and reading trackers may find a unified private dashboard more convenient.

### 14. OxiCloud — Personal cloud

**Project:** [GitHub](https://github.com/AtalayaLabs/OxiCloud) · [Releases](https://github.com/AtalayaLabs/OxiCloud/releases)

![OxiCloud — upstream project visual](https://raw.githubusercontent.com/AtalayaLabs/OxiCloud/HEAD/images/Captura%20de%20pantalla%202026-05-28%20a%20las%2022.35.08.png)

OxiCloud aims to provide files, calendars, contacts and office integration without the overhead of a large collaboration stack. Its v0.10.1 release on November 18 improved external mounts, quotas and contacts. The project is still pre-1.0, so test it with disposable data before considering a migration from Nextcloud or a NAS.

### 15. CommaFeed — RSS reader

**Project:** [GitHub](https://github.com/Athou/commafeed) · [Releases](https://github.com/Athou/commafeed/releases)

![CommaFeed — upstream project visual](https://user-images.githubusercontent.com/1256795/184886828-1973f148-58a9-4c6d-9587-ee5e5d3cc2cb.png)

CommaFeed is a responsive Google Reader-style feed reader with keyboard shortcuts and several layouts. Version 7.5.3 on November 19 fixed notification titles containing non-ASCII characters. It is a sensible Feedly alternative for anyone who wants a straightforward reading queue rather than algorithmic recommendations.

### 16. Opengist — Code snippets

**Project:** [GitHub](https://github.com/thomiceli/opengist) · [Releases](https://github.com/thomiceli/opengist/releases)

![Opengist — upstream project visual](https://raw.githubusercontent.com/thomiceli/opengist/master/public/img/opengist.svg)

Opengist stores snippets in Git repositories while providing a convenient browser interface. That design lets developers edit or retrieve snippets with familiar Git commands instead of depending on a proprietary paste service. It is a particularly useful private companion to a personal Git hosting installation.

### 17. Baserow — No-code databases

**Project:** [GitHub](https://github.com/baserow/baserow) · [Releases](https://github.com/baserow/baserow/releases)

![Baserow — upstream project visual](https://raw.githubusercontent.com/baserow/baserow/HEAD/docs/assets/screenshot.png)

Baserow provides spreadsheet-like databases, forms and application-building tools for teams. Its November 14 release fixed a field conversion issue involving select values. The open-source core is worth evaluating against Airtable for inventories and small internal tools, with paid feature boundaries checked before deployment.

### 18. textbee — SMS automation

**Project:** [GitHub](https://github.com/textbee/textbee) · [Releases](https://github.com/textbee/textbee/releases)

![textbee — upstream project visual](https://raw.githubusercontent.com/textbee/textbee/HEAD/.github/assets/dashboard-overview.png)

textbee turns an Android phone into an SMS gateway for applications and scripts. Version 2.10.0 on November 13 improved dual-SIM selection and reporting. It can complement a commercial messaging API for small, consent-based personal workflows, although carrier limits and phone availability still matter.

### 19. Zerobyte — Backup automation

**Project:** [GitHub](https://github.com/nicotsx/zerobyte) · [Releases](https://github.com/nicotsx/zerobyte/releases)

![Zerobyte — upstream project visual](https://github.com/nicotsx/zerobyte/blob/main/screenshots/backup-details.webp?raw=true)

Zerobyte provides a web interface for scheduling encrypted backups and restoring data from remote storage. Its November 9 release improved agent reliability during long backups. It earns an infrastructure slot because dependable backups directly enable the rest of this newsletter; always test a real restore before relying on it.

### 20. Scanopy — Network mapping

**Project:** [GitHub](https://github.com/scanopy/scanopy) · [Releases](https://github.com/scanopy/scanopy/releases)

![Scanopy — upstream project visual](https://raw.githubusercontent.com/scanopy/scanopy/HEAD/media/hero.png)

Scanopy discovers network devices and presents topology at several layers rather than requiring manually maintained diagrams. Version 0.20.1 on November 21 added clearer switch-ring layouts, speed-colored links and hop-by-hop path tracing. It is an unusually practical infrastructure discovery for anyone managing a growing home network.

## Notable Updates

### 1. FreshRSS 1.31.0 — November 23 · security

**Project:** [GitHub](https://github.com/FreshRSS/FreshRSS) · [Releases](https://github.com/FreshRSS/FreshRSS/releases)

![FreshRSS 1.31.0 — upstream project visual](https://raw.githubusercontent.com/FreshRSS/FreshRSS/edge/docs/img/FreshRSS-screenshot.png)

The maintainers describe this as a security-oriented release addressing several critical vulnerabilities. It also adds improved HTML parsing on PHP 8.4 and custom query sorting. PHP 8.2 is now the minimum, and the authentication change makes HTTPS especially important; review the [release notes](https://github.com/FreshRSS/FreshRSS/releases/tag/1.31.0) before upgrading.

### 2. Kimai 2.73.0 — November 23 · security

**Project:** [GitHub](https://github.com/kimai/kimai) · [Releases](https://github.com/kimai/kimai/releases)

![Kimai 2.73.0 — upstream project visual](https://raw.githubusercontent.com/kimai/images/main/repository-header.png)

The time-tracking platform fixed privileged profile management, supervisor API exposure and password login for SAML accounts. It also corrected yearly reporting and decimal duration rounding. Freelancers using it instead of Toggl or Harvest should review the [release notes](https://github.com/kimai/kimai/releases/tag/2.73.0) and update.

### 3. 2FAuth v9.0.3 — November 23 · security

**Project:** [GitHub](https://github.com/Bubka/2FAuth) · [Releases](https://github.com/Bubka/2FAuth/releases)

![2FAuth v9.0.3 — upstream project visual](https://user-images.githubusercontent.com/858858/100485897-18c21400-3102-11eb-9c72-ea0b1b46ef2e.png)

This security release fixes three advisories, including a high-severity authorization issue and a problem with shared authentication accounts. The application is a browser-based manager for one-time codes, making its security particularly consequential. Existing installations should prioritize the [update](https://github.com/Bubka/2FAuth/releases/tag/v9.0.3) and review their exposure.

### 4. Uptime Kuma 2.5.12 — November 17 · security

**Project:** [GitHub](https://github.com/louislam/uptime-kuma) · [Releases](https://github.com/louislam/uptime-kuma/releases)

![Uptime Kuma 2.5.12 — upstream project visual](https://user-images.githubusercontent.com/1336778/212262296-e6205815-ad62-488c-83ec-a5b0d0689f7c.jpg)

This maintenance release sandboxes a dangerous library and updates dependencies. It is included from the wider reporting window because monitoring services are often left running unattended for months. Review the [release notes](https://github.com/louislam/uptime-kuma/releases/tag/2.5.12) and back up the monitoring database before upgrading.

### 5. Infisical v0.167.16 — November 25 · secrets management

**Project:** [GitHub](https://github.com/infisical/infisical) · [Releases](https://github.com/infisical/infisical/releases)

![Infisical v0.167.16 — upstream project visual](https://raw.githubusercontent.com/infisical/infisical/HEAD/img/infisical_github_repo4.png)

This release adds a certificate policy option for including the common name as a DNS subject alternative name and makes secret imports respect change policies. These changes matter to teams managing application credentials and internal certificates. The open-source core can replace some hosted secrets workflows, but check enterprise feature boundaries and the [release notes](https://github.com/Infisical/infisical/releases/tag/v0.167.16).
