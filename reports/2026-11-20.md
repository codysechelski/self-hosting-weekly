# Self-Hosting Weekly — November 20, 2026

**Edition #13 · 25 projects · 20 discoveries and 5 notable updates**

This week brings useful alternatives for task capture, customer feedback, collaborative Markdown, finance and personal media. Start with **CollabMD**, **OpenTodo** and **Quackback**. Existing Coolify and wallabag installations deserve immediate attention because of verified security releases.

Research: upstream GitHub repository searches for activity since November 5, repository READMEs and release notes, checked November 20. Discoveries are not necessarily newly launched; star counts are approximate. Images link to assets listed by the projects themselves (relative README paths converted to raw URLs); they remain upstream property. Binary image rendering could not be independently checked by the text-only connector.

## New & Interesting

### 1. CollabMD — Collaborative Markdown

[Project repository](https://github.com/andes90/collabmd) · [Releases](https://github.com/andes90/collabmd/releases)

![CollabMD project visual](https://raw.githubusercontent.com/andes90/collabmd/master/docs/assets/collabmd-hero.webp)

A browser workspace for real-time editing of existing Markdown folders, diagrams and Git-backed documentation. Unlike a hosted wiki, it lets you retain an existing vault or documentation repository instead of migrating your files. With about 290 stars and active development, it is an especially compelling experiment for Obsidian users; test it on a copy of your vault first.

### 2. OpenTodo — Tasks and calendars

[Project repository](https://github.com/OpenTodoApp/OpenTodo) · [Releases](https://github.com/OpenTodoApp/OpenTodo/releases)

![OpenTodo project visual](https://raw.githubusercontent.com/OpenTodoApp/OpenTodo/main/docs/images/day-light.webp)

Natural-language task capture, project boards, offline synchronization and calendar-based planning make this a credible Todoist-style alternative. It also offers browser and mobile capture routes for getting tasks into an inbox quickly. The project has roughly 600 stars and is worth testing for a personal workflow before migrating a shared task list.

### 3. Quackback — Product feedback

[Project repository](https://github.com/QuackbackIO/quackback) · [Releases](https://github.com/QuackbackIO/quackback/releases)

![Quackback project visual](https://raw.githubusercontent.com/QuackbackIO/quackback/main/.github/readme/hero-light.svg)

Feedback boards, a public roadmap, changelog, help center and support inbox live together in this self-hostable product. It is a particularly appealing Canny alternative for independent software developers who would otherwise pay several subscriptions to communicate with customers. The AGPL project has around 370 stars and its README says the self-hosted edition includes unlimited seats without a license key; email and optional AI providers remain your responsibility.

### 4. LaSuite Drive — File sharing

[Project repository](https://github.com/suitenumerique/drive) · [Releases](https://github.com/suitenumerique/drive/releases)

![LaSuite Drive project visual](https://raw.githubusercontent.com/suitenumerique/drive/main/docs/assets/Drive_screenshot.png)

This open-source file storage and sharing application emphasizes granular permissions and collaboration. It comes from the French public-sector LaSuite ecosystem and has around 490 stars. Consider it for a small team that needs a Drive-like portal, but compare deployment complexity with the file-sharing tools already available on a NAS.

### 5. Relaticle — CRM

[Project repository](https://github.com/relaticle/relaticle) · [Releases](https://github.com/relaticle/relaticle/releases)

![Relaticle project visual](https://raw.githubusercontent.com/relaticle/relaticle/main/public/images/github-preview-light.png)

A customizable CRM with pipelines, workspace isolation, custom fields and an API. Its optional agent integration is prominent, but the underlying CRM is the reason to consider it as an alternative to paid contact and opportunity trackers. Around 1,900 stars indicate interest; its six-container Compose deployment is better suited to a capable server than a tiny appliance.

### 6. Urlaubsverwaltung — Leave management

[Project repository](https://github.com/urlaubsverwaltung/urlaubsverwaltung) · [Releases](https://github.com/urlaubsverwaltung/urlaubsverwaltung/releases)

This German-origin web application handles employee absence requests, approvals, sick leave and overtime. It is a focused alternative to buying a complete HR suite simply to manage time off. The Apache-licensed project has around 300 stars, publishes Docker images and is worth evaluating for small teams that can accommodate its localization and policy model.

### 7. FOSSBilling — Client billing

[Project repository](https://github.com/FOSSBilling/FOSSBilling) · [Releases](https://github.com/FOSSBilling/FOSSBilling/releases)

![FOSSBilling project visual](https://raw.githubusercontent.com/FOSSBilling/branding/refs/heads/main/assets/light-background/fossbilling-logo.svg)

A billing and client-management platform aimed particularly at hosting and service businesses, with invoices, checkout and payment modules. It can replace parts of a commercial hosting billing system rather than a general-purpose accounting package. The Apache-licensed project has about 1,750 stars, and its October 23 release hardened authentication and payment flows; review payment integration changes before deploying.

### 8. Aurral — Music discovery

[Project repository](https://github.com/lklynet/aurral) · [Releases](https://github.com/lklynet/aurral/releases)

![Aurral project visual](https://raw.githubusercontent.com/lklynet/aurral/main/web/screenshots/discover.webp)

A music discovery and acquisition workflow with optional integrations for several download sources. It can complement a local music library when discovery and queue management are fragmented across tools. The MIT project has about 2,200 stars and a Compose example; use only sources and media you are authorized to access.

### 9. Wealthfolio — Personal finance

[Project repository](https://github.com/wealthfolio/wealthfolio) · [Releases](https://github.com/wealthfolio/wealthfolio/releases)

![Wealthfolio project visual](https://raw.githubusercontent.com/wealthfolio/wealthfolio/main/apps/frontend/public/screenshot.webp)

An investment and net-worth tracker with spending and simulation tools, available as a local-first application and a self-hosted web deployment. It offers a private alternative to subscription portfolio dashboards. With roughly 9,600 stars and documented Docker authentication and encryption options, it is a polished candidate, although you should validate holdings and backups before relying on its calculations.

### 10. Kavita — Digital reading

[Project repository](https://github.com/Kareadita/Kavita) · [Releases](https://github.com/Kareadita/Kavita/releases)

![Kavita project visual](https://github.com/user-attachments/assets/f016b34f-3c4c-4f07-8e72-12cd6f4e71ea)

A browser-accessible reading server for personal ebook and comic collections. It offers a central library and reading experience without needing to upload books to a commercial service. The GPL project has about 12,000 stars; its core is free, while some optional metadata and recommendation features belong to Kavita+.

### 11. Appsmith — Internal applications

[Project repository](https://github.com/appsmithorg/appsmith) · [Releases](https://github.com/appsmithorg/appsmith/releases)

![Appsmith project visual](https://raw.githubusercontent.com/appsmithorg/appsmith/release/static/appsmith_logo_white.png)

A low-code platform for building dashboards and administration interfaces backed by databases and APIs. It can replace a paid Retool-style subscription for suitable internal tools. With over 41,000 stars it is a mature candidate, but review community versus enterprise features and allocate enough memory for its deployment.

### 12. Traccar — GPS tracking

[Project repository](https://github.com/traccar/traccar) · [Releases](https://github.com/traccar/traccar/releases)

![Traccar project visual](https://raw.githubusercontent.com/traccar/traccar/master/.github/screenshot.png)

A self-hosted GPS tracking platform for compatible vehicles and devices, with a web dashboard and REST API. It supports a broad range of device protocols and can replace recurring fleet-tracking software when you already own compatible hardware. Its approximately 8,200 stars reflect an established project; configure authentication and location-data retention carefully.

### 13. YTPTube — Media downloads

[Project repository](https://github.com/arabcoders/ytptube) · [Releases](https://github.com/arabcoders/ytptube/releases)

![YTPTube project visual](https://raw.githubusercontent.com/arabcoders/ytptube/dev/sc_short.jpg)

A web front end and automation layer for yt-dlp, supporting queued downloads, recurring sources and metadata-based rules. It can replace manual command-line runs for permitted media downloads and personal archival workflows. The MIT project has around 1,100 stars; storage limits and the terms of the source services are important considerations.

### 14. Silo — Media library

[Project repository](https://github.com/Silo-Server/silo-server) · [Releases](https://github.com/Silo-Server/silo-server/releases)

![Silo project visual](https://raw.githubusercontent.com/Silo-Server/silo-server/main/assets/icon.png)

A self-hosted server covering movies, series, audiobooks, ebooks, podcasts and manga. Its appeal is consolidating several media libraries rather than running a separate service for each type. With around 1,100 stars and a documented Compose deployment it earns a trial, although existing Jellyfin and reading-server users should test client support before switching.

### 15. Ovumcy — Personal health journal

[Project repository](https://github.com/ovumcy/ovumcy-web) · [Releases](https://github.com/ovumcy/ovumcy-web/releases)

![Ovumcy project visual](https://raw.githubusercontent.com/ovumcy/ovumcy-web/main/docs/screenshots/dashboard.jpg)

A private cycle-tracking web application with calendar estimates and daily logging. Self-hosting is especially appealing for this category because the records can be highly sensitive. This AGPL project has around 140 stars and is still a smaller undertaking; treat predictions as estimates rather than medical or contraceptive advice and protect backups.

### 16. Messer Swipe — Shared watch decisions

[Project repository](https://github.com/jakobbjelver/messer-swipe) · [Releases](https://github.com/jakobbjelver/messer-swipe/releases)

![Messer Swipe project visual](https://raw.githubusercontent.com/jakobbjelver/messer-swipe/master/docs/brand/banner-light.png)

A mobile-first group swiping tool that finds movies people agree to watch. It can use Jellyfin, Plex or Emby libraries, or operate against TMDB independently, with a small SQLite database for sessions. The MIT project has roughly 800 stars and is a focused practical companion to an existing media server rather than another library manager.

### 17. Open Mercato — Business application framework

[Project repository](https://github.com/open-mercato/open-mercato) · [Releases](https://github.com/open-mercato/open-mercato/releases)

![Open Mercato project visual](https://raw.githubusercontent.com/open-mercato/open-mercato/main/.github/readme/kaldi-orders-light.png)

A TypeScript and PostgreSQL framework with ready-made CRM, ERP and commerce modules. It could save a developer from building a custom business back office entirely from scratch. With about 2,000 stars it is an interesting emerging platform, although it is more of a development foundation than a turnkey replacement for business SaaS.

### 18. BirdNET-Go — Garden audio monitoring

[Project repository](https://github.com/tphakala/birdnet-go) · [Releases](https://github.com/tphakala/birdnet-go/releases)

![BirdNET-Go project visual](https://raw.githubusercontent.com/tphakala/birdnet-go/main/doc/BirdNET-Go-dashboard.webp)

A Raspberry Pi-friendly service that identifies bird calls locally from a microphone or network audio stream and displays detections in a web dashboard. This is a narrow exception to the usual avoidance of AI because local classification is the actual utility and does not require an AI subscription. Around 2,500 stars and ARM64 Docker images make it an interesting home project; review the separate noncommercial terms for model or data components.

### 19. Pulse — Homelab monitoring

[Project repository](https://github.com/rcourtman/Pulse) · [Releases](https://github.com/rcourtman/Pulse/releases)

![Pulse project visual](https://raw.githubusercontent.com/rcourtman/Pulse/main/docs/images/pulse-workspace.png)

A monitoring workspace for homelab systems, with a dashboard that brings infrastructure health into one place. It is worth trying if several servers or virtualization hosts are becoming difficult to monitor separately. The MIT repository has about 7,100 stars; for a single Pi, a simpler uptime monitor may remain sufficient.

### 20. Radar — Kubernetes visibility

[Project repository](https://github.com/skyhook-io/radar) · [Releases](https://github.com/skyhook-io/radar/releases)

![Radar project visual](https://raw.githubusercontent.com/skyhook-io/radar/main/docs/screenshots/topology-view.png)

A Kubernetes interface for exploring unhealthy workloads, resource relationships, changes, Helm and GitOps activity. Its visual topology and timeline are valuable independently of its optional agent integrations. With over 4,100 stars and an Apache license it is worth investigating for cluster operators, though it is unnecessary for a straightforward Docker Compose home server.

## Notable Updates

### 1. wallabag 2.6.18 — November 19

[Project repository](https://github.com/wallabag/wallabag) · [Release notes](https://github.com/wallabag/wallabag/releases/tag/2.6.18)

![wallabag 2.6.18 project visual](https://raw.githubusercontent.com/wallabag/wallabag/master/.github/images/screenshot.png)

This security release validates imported tagging rules, restricts public-share links to HTTP(S), prevents EPUB export from reading files or fetching URLs supplied by entry content, and updates SVG sanitization. Remote images in EPUB exports now remain links rather than being embedded. The maintainers instruct users to clear the cache and review tagging rules after upgrading; this is a priority for exposed installations.

### 2. Coolify v4.7.6 — November 19

[Project repository](https://github.com/coollabsio/coolify) · [Release notes](https://github.com/coollabsio/coolify/releases/tag/v4.7.6)

![Coolify v4.7.6 project visual](https://raw.githubusercontent.com/coollabsio/coolify/main/.github/assets/screenshots/dashboard-light.png)

The maintainers recommend immediate updates because the release patches critical vulnerabilities in upstream PHP, nginx and Node.js dependencies. It also binds PHP-FPM to loopback inside its container and tightens nginx defaults for sensitive files. If you use Coolify as a self-hosted deployment platform, prioritize this update rather than waiting for a feature release.

### 3. Arcane v3.1.1 — November 19

[Project repository](https://github.com/getarcaneapp/arcane) · [Release notes](https://github.com/getarcaneapp/arcane/releases/tag/v3.1.1)

![Arcane v3.1.1 project visual](https://raw.githubusercontent.com/getarcaneapp/arcane/main/.github/assets/arcane-dash-v3-dark.jpg)

Overlapping scheduled volume and system backups now run sequentially instead of being skipped. The release also restores root ownership and permissions for new volumes and adds Compose job runs in projects. These are meaningful reliability changes for users depending on Arcane to manage and back up containers.

### 4. Immich v3.4.2 — November 18

[Project repository](https://github.com/immich-app/immich) · [Release notes](https://github.com/immich-app/immich/releases/tag/v3.4.2)

![Immich v3.4.2 project visual](https://raw.githubusercontent.com/immich-app/immich/main/design/immich-screenshots.png)

This patch includes a new FUTO Backups version and fixes integrity-report downloads, alongside slideshow, metadata UI and video-acceleration bugs. The integrity-report correction is especially relevant to users relying on Immich for a personal photo archive. Review the release notes and confirm backups before upgrading.

### 5. PhotoPrism 261029-963b58c50 — October 29

[Project repository](https://github.com/photoprism/photoprism) · [Release notes](https://github.com/photoprism/photoprism/releases/tag/261029-963b58c50)

![PhotoPrism 261029-963b58c50 project visual](https://dl.photoprism.app/img/ui/2025/desktop-search.jpg)

This release upgrades the database layer with experimental PostgreSQL support, adds selected-resolution export in the photo viewer, and improves maps and metadata handling. It also adds OAuth-connected MCP tools for optional library integrations. The database changes are significant for a long-running photo library, but PostgreSQL support remains experimental; this release is included from the wider 30-day window.
