# Self-Hosting Weekly

## October 30, 2026 · Edition #10

**27 projects · 22 new discoveries · 5 notable updates**

This week's theme is **getting useful software back under your control**. There are several especially interesting newcomers, including a Todoist alternative that runs in a single Go container, a Git-backed Markdown wiki, a self-hosted Canva competitor, and a visual website builder that's gained thousands of GitHub stars.

I've also included some mature applications that haven't appeared in recent editions, particularly in invoicing, private analytics, and everyday developer utilities. The focus remains on software that replaces paid SaaS, not more infrastructure to maintain.

## New & Interesting

### 1. OpenTodo — A Todoist replacement that fits on a Raspberry Pi

![OpenTodo project icon](https://raw.githubusercontent.com/OpenTodoApp/OpenTodo/main/web/public/pwa-192.png)

**Productivity · Go / SQLite · AGPL-3.0 · ~190 stars**

[GitHub](https://github.com/OpenTodoApp/OpenTodo) · [Website](https://open-todo.app)

OpenTodo combines Todoist-style natural-language entry, recurring tasks, projects, boards, reminders, and shared workspaces with offline-first synchronization. Its Go server uses one SQLite database, and the maintainer reports approximately 20 MB idle memory usage, with ARM64 Docker images and Synology deployment instructions. It also has a CLI, CalDAV, importers for commercial task managers, and optional encryption. The project is still pre-1.0 and heavily AI-assisted in development, but its documented tests and architecture make it one of the more promising newcomers.

**Why it earned the top spot:** The combination of a genuinely useful feature set, a tiny footprint, and keyboard-first operation is unusually attractive. I'd test this before considering another large productivity platform.

### 2. Vasta — Capacities and Notion, without the cloud dependency

<!-- image: Vasta workspace UI -->

**Knowledge management · Vue 3 / Node / SQLite · AGPL-3.0**

[GitHub](https://github.com/ariedotme/vasta)

Vasta organizes information as typed objects—books, people, tasks, meetings, or custom types—with relationships and table, board, gallery, and list views. It combines daily notes, habits, calendars, shared spaces, and an inbox that accepts information from a browser extension or Telegram. The application uses a local SQLite replica in the browser for offline work, while the server runs in one Docker container. It's an early-stage project with AI-assisted implementation and still needs broader cross-platform testing.

**Why it's here:** A local-first workspace built with Vue 3 and Node is particularly interesting when the goal is to replace several small productivity subscriptions with one application.

### 3. Hold My Docs — A wiki where every save is a Git commit

![Hold My Docs interface](https://raw.githubusercontent.com/soollabs/holdmydocs/main/docs/hero.png)

**Documentation · Go / Git · MIT · New project**

[GitHub](https://github.com/soollabs/holdmydocs) · [Documentation](https://hmd.sool.dev)

Hold My Docs stores wiki pages as ordinary Markdown files in a Git repository, automatically committing changes to provide history, diffs, and rollback. It supports wiki links, backlinks, Mermaid diagrams, attachments, full-text search, OIDC, and static-site export. The application runs as a single Go binary or Docker container, with no database server required. Its author acknowledges early-stage limitations, particularly around divergent Git histories.

**Why it's here:** This is an especially good match for a workflow built around Neovim, Git, and Markdown. Your documentation remains useful even if you eventually stop running the application.

### 4. Doory — A rapidly growing self-hosted Canva alternative

![Doory graphic design editor](https://raw.githubusercontent.com/shaongitbd/doory/main/.github/readme/editor.webp)

**Creative tools · React / Django · ~1.7K+ stars**

[GitHub](https://github.com/shaongitbd/doory) · [Website](https://doory.art)

Doory is a browser-based graphic-design editor for social posts, invitations, presentations, business cards, and marketing assets. It includes layers, animations, brand kits, templates, collaboration, and exports to formats including PNG, SVG, PDF, and MP4. Launched in October, it had already reached approximately 1,700 GitHub stars by October 21, an impressive start for a new application. It is self-hostable through Docker Compose and uses the OSI-listed Attribution Assurance License, which requires visible author credit in redistributed installations.

**Why it's here:** It's a genuinely practical alternative to paying for Canva when you need occasional design work, though its template library and maturity are not yet comparable.

### 5. Instatic — A visual website builder that publishes clean HTML

![Instatic visual CMS](https://raw.githubusercontent.com/CoreBunch/Instatic/main/docs/assets/readme/build-components.webp)

**Web publishing · Bun / SQLite · MIT · ~9K stars**

[GitHub](https://github.com/CoreBunch/Instatic)

Instatic combines a visual page builder, CMS, forms, media management, reusable components, and publishing in one Bun-based server. Unlike many visual builders, its goal is to produce semantic HTML and compact CSS rather than shipping a large runtime to every visitor. It supports SQLite or PostgreSQL, and the project comes from developers with established WordPress design-tool experience. Its repository reached roughly 9,000 stars and was updated October 29, but it remains pre-1.0 with APIs that may change.

**Why it's here:** This is one of the more intriguing attempts to replace Webflow, Framer, and combinations of CMS and form-builder subscriptions. Its optional AI editing isn't required for the core visual workflow.

### 6. Umami — Privacy-conscious analytics without Google Analytics

<!-- image: Umami analytics dashboard -->

**Web analytics · MIT · ~39.8K stars**

[GitHub](https://github.com/umami-software/umami) · [Website](https://umami.is)

Umami provides website and product analytics with traffic reports, campaigns, events, conversions, and visitor-behavior information. It emphasizes cookieless tracking and avoiding invasive visitor surveillance, with data stored in your own deployment. Its mature community and approximately 40,000 stars make it a substantially lower-risk choice than a brand-new analytics application. The tradeoff is that self-hosting still requires a database and responsible decisions about which events to collect.

**Why it's here:** This is especially relevant for privacy-conscious websites where visitors should understand what is being measured. It deserves a serious comparison with the more elaborate Rybbit featured earlier this month.

### 7. IT-Tools — A toolbox of everyday developer utilities

<!-- image: IT-Tools dashboard -->

**Developer utilities · Vue / TypeScript · GPL-3.0 · ~41K stars**

[GitHub](https://github.com/CorentinTh/it-tools) · [Demo](https://it-tools.tech)

IT-Tools collects useful developer utilities into one polished web interface, covering text transformation, encoding, data formatting, cryptographic helpers, and other common tasks. Most of the value comes from small operations that would otherwise require searching for a random website or remembering another command-line invocation. The application is open source and can be served locally, with no subscription or account needed for the tools. Its 41,000-star community makes it one of the more established utility collections.

**Why it's here:** This is an easy addition to a personal internal tools domain, especially for someone regularly working with JSON, URLs, tokens, and text transformations.

### 8. VERT — File conversion in the browser, not someone else's cloud

<!-- image: VERT file converter -->

**File conversion · Svelte / WebAssembly · AGPL-3.0 · ~16K stars**

[GitHub](https://github.com/VERT-sh/VERT) · [Website](https://vert.sh)

VERT converts images, documents, audio, and other files using WebAssembly wherever the browser can handle the conversion. It supports more than 250 formats and can be self-hosted through Docker. Some video conversions need a server-side daemon, which can also be self-hosted instead of using the public service. Its clear privacy model and established community make it an appealing alternative to uploading sensitive files to random conversion websites.

**Why it's here:** It pairs nicely with BentoPDF from a previous edition: one for PDF-specific work, the other for general file conversions.

### 9. SolidInvoice — A mature, genuinely open-source invoicing platform

<!-- image: SolidInvoice dashboard -->

**Invoicing · Symfony / PHP · MIT · ~980 stars**

[GitHub](https://github.com/SolidInvoice/SolidInvoice) · [Website](https://solidinvoice.co)

SolidInvoice handles quotations, invoices, recurring billing, taxes, currencies, and payment collection for freelancers and small businesses. It has a long development history, but the current codebase is being modernized around Symfony 7 and PHP 8.4. It offers Docker deployment as well as native installation options, and the self-hosted edition is MIT licensed rather than a restricted commercial source release. Its repository remained active through October 28, with version 3.1.2 released October 21.

**Why it's here:** After the maintenance problems noted with PHP Ledger earlier this month, SolidInvoice is worth examining as a more established option for ordinary small-business invoicing.

### 10. InvoiceShelf — A focused FreshBooks alternative

<!-- image: InvoiceShelf dashboard -->

**Invoicing · Laravel / PHP · AGPL-3.0 · ~1.9K stars**

[GitHub](https://github.com/InvoiceShelf/InvoiceShelf)

InvoiceShelf provides invoices, estimates, payment records, expenses, recurring billing, and customer portals. ### 11. Bigcapital — Full accounting without QuickBooks

<!-- image: Bigcapital accounting UI -->

[GitHub](https://github.com/bigcapitalhq/bigcapital) · [Website](https://bigcapital.app)

### 22. Telltale DNS — An infrastructure exception worth watching

<!-- image: Telltale DNS dashboard -->

**Networking · Rust · ARM64 / ARMv7 · Pre-1.0**

[GitHub](https://github.com/paimonsoror/telltaledns)

Telltale DNS is a new DNS resolver and blocker designed to explain *why* a request was allowed, blocked, or resolved to a particular address. It supports per-device rules, encrypted DNS, Git-managed configuration, and synchronization across multiple resolver instances. The developer reports running it on a Raspberry Pi 4 and a Kubernetes cluster, with Docker images for several ARM architectures. It is still pre-1.0 and heavily AI-assisted in development, so I would test it on a noncritical network before replacing a trusted DNS service.

**Why it earned the infrastructure exception:** The explainability and Git-based configuration are genuinely useful improvements over conventional DNS blocking, especially for a network with many devices and custom internal DNS records.

## What I'd actually install or test

### OpenTodo — First experiment

I'd start with a test instance on the Raspberry Pi 5. Its single-container deployment, SQLite storage, natural-language task entry, CLI, and Vim-friendly keyboard controls are unusually well aligned with a terminal-heavy workflow. Keep it separate from an established task system until synchronization and reminders have been tested.

### Hold My Docs — Most interesting architecture

Git-backed Markdown with automatic history and static export is an excellent foundation for documentation that needs to outlive its editor. I'd experiment with a small repository of project notes or runbooks rather than moving a complete knowledge base immediately.

### Umami — Most sensible production candidate

For a small website or collection of personal projects, Umami is one of the strongest candidates for a privacy-respecting analytics installation. It's more established than the new tools, and the functionality directly addresses a recurring SaaS expense.

### Doory — Most promising creative newcomer

The rapid early traction is interesting, and a self-hosted design editor could become genuinely useful for graphics, thumbnails, and simple marketing materials. I would evaluate the editing experience and export quality before replacing any existing design software.

### VERT — Easiest everyday utility

A private file-conversion page is something almost anyone can use immediately. Its browser-first design makes it particularly attractive for a lightweight personal tools collection.

## Curation notes

This week surfaced a useful contrast between the **new generation of tiny, single-container applications** and mature self-hosted platforms with tens of thousands of users. OpenTodo, Hold My Docs, and Vasta are attractive because their architectures are straightforward and their data is portable. Umami, Appsmith, and drawDB offer greater confidence from their established communities, but they aren't necessarily the smallest applications to operate.

The other trend is how quickly new projects are being developed with coding agents. Many October newcomers openly disclose heavy AI assistance. I've treated that as a reason to examine tests, documentation, security boundaries, and maintenance expectations more carefully—not as automatic proof that a project is good or bad.

One important licensing distinction also emerged: not everything described as *self-hostable* is genuinely open source. I excluded projects using restrictive source-available licenses from the main recommendations, and identified commercial or mixed-license components where relevant.

**This week's balance:** 81.5% productivity, utilities and SaaS replacements; 18.5% infrastructure and automation.

**Overall winner:** OpenTodo for experimentation, Umami for a dependable installation. OpenTodo has the more exciting architecture and feature combination, but Umami is the more mature candidate for a service that can simply run and provide value.

The direction remains the same: fewer applications that exist just to manage servers, and more applications that make owning your own software worthwhile.
