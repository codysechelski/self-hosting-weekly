# Self-Hosting Weekly — November 6, 2026

**Edition #11 · 25 picks · 20 newly featured projects + 5 notable updates**

This week is about practical tools you can actually put to work: lightweight file portals, Markdown knowledge bases, task trackers, bookmark managers, mail utilities and a few focused developer tools. The emphasis is on useful alternatives to subscriptions, not on collecting another twenty infrastructure dashboards. **“New & Interesting” means newly featured here, not necessarily newly launched this week.**

**Three worth testing first:** Mikochi for NAS browsing, SilverBullet for Markdown-centric knowledge management, and Dagu for keeping shell automation understandable. **Most urgent update:** Vikunja v2.8.0, which addresses security issues. Dates below are from upstream release information available on November 6; verify release notes before upgrading production services.

Images are omitted where a reliable upstream-hosted screenshot URL could not be verified; no stock imagery or guessed asset links are used.

## New & Interesting

### 1. Mikochi — File browser · NAS

**Project:** [Mikochi](https://github.com/zer0tonin/mikochi) · **Release/activity reference:** [source](https://selfhost.directory/project/mikochi)

A deliberately small web file manager that handles uploads, downloads, renaming and directory browsing without installing a full cloud suite. It can generate streaming links for VLC or mpv, making it attractive for a NAS with media already on disk. Version 1.13.3 (November 3) added a path-prefix option, handy behind an existing reverse proxy.

### 2. FileRise — File sharing · Box alternative

**Project:** [FileRise](https://selfhost.directory/project/filerise) · **Release/activity reference:** [source](https://selfhost.directory/project/filerise)

FileRise offers a browser-based file portal with access controls and share links, useful when full Nextcloud feels excessive. Its November 3 security change binds file-share URLs to file identities rather than just paths. **Upgrade caveat:** older individual-file links must be recreated after v3.40.0; the November 5 v3.42.0 release also hardens OIDC behavior.

### 3. SilverBullet — Markdown knowledge base · Notion alternative

**Project:** [SilverBullet](https://github.com/silverbulletmd/silverbullet) · **Release/activity reference:** [source](https://selfhost.directory/project/silverbullet)

SilverBullet treats Markdown pages as a programmable personal knowledge system with backlinks, queries, templates and Lua scripting. A browser-first interface is a good fit for a vault that should remain editable outside the app. The October 12 v2.12.1 release keeps this actively maintained, though its scripting model takes more learning than a basic notes app.

### 4. Shaarli — Bookmarks · Link sharing

**Project:** [Shaarli](https://github.com/shaarli/Shaarli) · **Release/activity reference:** [source](https://selfhost.directory/project/shaarli)

Shaarli is a lightweight, self-hosted bookmarking and link-sharing application with tags, search, RSS feeds and import/export. Unlike feature-heavy read-it-later systems, its appeal is a simple archive of useful URLs and notes. The project shipped v0.16.10 on October 21, making it a practical option for replacing a collection of browser-synced bookmarks.

### 5. Chhoto URL — Short links · Bitly alternative

**Project:** [Chhoto URL](https://selfhost.directory/project/chhoto-url) · **Release/activity reference:** [source](https://selfhost.directory/project/chhoto-url)

Chhoto URL lets you run your own URL shortener under a domain you control rather than rely on a hosted link service. The November 2 v7.10.7 release improved the mobile information table and support for custom OIDC certificates. This is a nice small utility to place behind an existing reverse proxy, especially for blog and documentation links.

### 6. Cypht — Email · Webmail

**Project:** [Cypht](https://github.com/cypht-org/cypht) · **Release/activity reference:** [source](https://selfhost.directory/project/cypht)

Cypht aggregates multiple email accounts into a single browser interface without requiring you to run an entire mail server. Its November 6 v2.14.0 release added web-based configuration and AMP-for-Email handling while fixing SMTP and saved-search behavior. It is worth investigating if you want a self-hosted mail-reading front end, not a Gmail replacement for mail delivery.

### 7. Group-Office — Office suite · Google Workspace alternative

**Project:** [Group-Office](https://www.group-office.com/) · **Release/activity reference:** [source](https://selfhost.directory/project/groupoffice)

Group-Office bundles calendars, contacts, email, files and business collaboration tools into a self-hosted workspace. It is substantially heavier than a single-purpose utility, but can replace several small subscriptions for a team. Multiple maintained branches had releases November 2–4; evaluate edition/licensing boundaries and deployment needs before committing.

### 8. Kitsu — Creative projects · ShotGrid alternative

**Project:** [Kitsu](https://www.cg-wire.com/kitsu) · **Release/activity reference:** [source](https://selfhost.directory/project/kitsu)

Kitsu tracks animation, VFX and game productions through assignments, asset pipelines, reviews and schedules. It is specialized rather than general-purpose project management, which is exactly why it may be valuable to small creative studios. Version 1.0.77 arrived November 4; PostgreSQL, Redis and other components make this a heavier deployment.

### 9. Super Productivity — Tasks · Time tracking

**Project:** [Super Productivity](https://github.com/johannesjo/super-productivity) · **Release/activity reference:** [source](https://selfhost.directory/project/super-productivity)

Super Productivity combines personal task planning, time tracking and integrations with issue trackers. It can sync through WebDAV or Dropbox, making it appealing when you want to keep data under your control without hosting a large task-management server. October's v19.2.0 introduced numeric task priorities; compare its desktop-first approach with Vikunja or OpenTodo.

### 10. Wakapi — Developer analytics · WakaTime alternative

**Project:** [Wakapi](https://github.com/muety/wakapi) · **Release/activity reference:** [source](https://selfhost.directory/project/wakapi)

Wakapi records editor activity to a dashboard you control, a direct alternative to hosted coding-time trackers. Its small footprint is attractive for a Raspberry Pi or home server and the data can stay private. The October 14 v2.18.2 release adds a database index; large existing datasets may take significant time to migrate.

### 11. SimpleLogin — Email aliases · Hide My Email alternative

**Project:** [SimpleLogin](https://github.com/simple-login/app) · **Release/activity reference:** [source](https://selfhost.directory/project/simplelogin)

SimpleLogin creates forwarding aliases so you can avoid giving every site your real address. Self-hosting gives you control over the alias domain and delivery path, although mail infrastructure and DNS reputation add operational work. November 3–4 updates improved metrics, email-handler reliability and administrator lookup.

### 12. FileGator — File portal · FTP alternative

**Project:** [FileGator](https://github.com/filegator/filegator) · **Release/activity reference:** [source](https://selfhost.directory/project/filegator)

FileGator is a browser-based file manager with upload, download and sharing workflows. It can be a useful alternative to handing occasional users raw FTP/SFTP access. **Security note:** its October 21 v7.16.8 release addressed critical PHP vulnerabilities affecting the Docker image; November 4 v7.16.9 followed.

### 13. kodbox — Team files · Cloud drive

**Project:** [kodbox](https://github.com/kalcaddle/kodbox) · **Release/activity reference:** [source](https://selfhost.directory/project/kodbox)

kodbox offers a file-management interface with personal, departmental and organization-wide spaces. It aims at a more polished team-drive experience than a simple file browser, but comes with more configuration and administration. The 1.71 series was released November 4–5; check language, authentication and mobile-client fit before replacing an existing NAS workflow.

### 14. shelfmark — Books · Personal library utility

**Project:** [shelfmark](https://selfhost.directory/project/shelfmark) · **Release/activity reference:** [source](https://selfhost.directory/project/shelfmark)

shelfmark is a self-hosted book-related utility with a web interface, queue and metadata-related routes. The November 2 v1.6.1 release reorganized its backend into smaller modules while keeping the same URL map. This is more of a specialist library workflow than a general document system, so review the upstream project's exact acquisition and library features before deploying.

### 15. Bar Assistant — Recipes · Personal inventory

**Project:** [Bar Assistant](https://github.com/karlomikus/bar-assistant) · **Release/activity reference:** [source](https://selfhost.directory/project/bar-assistant)

Bar Assistant manages cocktail recipes, ingredients, substitutions and what you have on hand. It is a good example of a narrow, polished personal utility that does not need an ongoing SaaS subscription. Version 6.11.0 on November 5 improved ingredient filtering and introduced configurable login-token expiration; its optional photo recognition requires an AI provider.

### 16. Atuin — CLI productivity · Shell history

**Project:** [Atuin](https://github.com/atuinsh/atuin) · **Release/activity reference:** [source](https://selfhost.directory/project/atuin)

Atuin makes shell history searchable across machines and can use a self-hosted synchronization server. For a terminal-heavy workflow spanning a Mac and Raspberry Pis, it offers value without introducing a browser dashboard for everything. November 4 v18.24.5 includes history-search fixes, new onboarding and additional session-capture features.

### 17. Dagu — Automation · Cron alternative

**Project:** [Dagu](https://github.com/dagu-org/dagu) · **Release/activity reference:** [source](https://selfhost.directory/project/dagu)

Dagu provides a web interface for scheduling and observing workflows defined in YAML, with a visual graph and activity view. It is worth considering when a growing collection of shell scripts and cron jobs becomes difficult to manage. The November 5 v2.25.7 release focused on fixing regressions in the workflow editor and improving how panels preserve state.

### 18. awl — Networking · Tailscale alternative

**Project:** [awl](https://selfhost.directory/project/awl) · **Release/activity reference:** [source](https://selfhost.directory/project/awl)

awl builds a peer-to-peer mesh network with automatic discovery, hostnames and optional exit-node or SOCKS5 routing. Unlike centrally coordinated alternatives, its architecture is decentralized, though that also changes how it is administered and supported. Version 0.20.0 arrived October 24; this is one to test in isolation before replacing a dependable Tailscale setup.

### 19. Zot Registry — Developer infrastructure · OCI registry

**Project:** [Zot Registry](https://github.com/project-zot/zot) · **Release/activity reference:** [source](https://selfhost.directory/project/zot-registry)

Zot is an OCI image registry for teams that want control over where container artifacts live. It is infrastructure rather than an everyday app, but a compact registry can simplify reproducible deployments across several small servers. November 2 v2.1.23 added per-user repository namespaces and improved sync behavior, alongside storage and certificate fixes.

### 20. Lemmy — Communities · Reddit alternative

**Project:** [Lemmy](https://github.com/LemmyNet/lemmy) · **Release/activity reference:** [source](https://en.wikipedia.org/wiki/Lemmy_(social_network))

Lemmy lets communities run discussion forums and federate with other instances using ActivityPub. It is a genuine self-hosted alternative to centralized community platforms, though moderation and federation require active attention. The October 26 v0.19.21 release makes it a timely candidate for people who want to own a community's infrastructure.

## Notable Updates

### 1. Vikunja — Task management

**Project:** [Vikunja](https://github.com/go-vikunja/vikunja) · **Release notes:** [source](https://selfhost.directory/project/vikunja)

**November 5: v2.8.0.** This is an important security release addressing 19 reported issues, with a new trash bin/undo flow and improved linking between local and SSO accounts. October 20's v2.7.1 had also addressed 41 security issues, so existing installations should prioritize upgrades rather than new features.

### 2. Arcane — Docker management

**Project:** [Arcane](https://github.com/getarcaneapp/arcane) · **Release notes:** [source](https://selfhost.directory/project/arcane)

**November 4: v2.17.3.** The release fixes pending image-update planning and Compose image reporting, and redacts secrets from logged request paths. It is an operational-quality update rather than a flashy feature release, but useful for people administering containers from a web UI.

### 3. n8n — Workflow automation

**Project:** [n8n](https://github.com/n8n-io/n8n) · **Release notes:** [source](https://selfhost.directory/project/n8n)

**November 4: v2.47.2 / v2.46.6.** These releases fix broken npm installation paths and improve expression and credential handling. n8n remains powerful for Zapier-like workflows, but its source-available fair-code licensing is not the same as OSI-approved open source; include it as a clearly labeled licensing exception.

### 4. frp — Reverse proxy

**Project:** [frp](https://github.com/fatedier/frp) · **Release notes:** [source](https://selfhost.directory/project/frp)

**November 4: v0.72.0.** frp added certificate verification against system CAs, hot-reloading for HTTPS proxy certificates and a separate metrics listener. It is a useful security/observability upgrade for anyone exposing internal services through a public VPS.

### 5. Immich — Photo library

**Project:** [Immich](https://github.com/immich-app/immich) · **Release notes:** [source](https://github.com/immich-app/immich/releases)

**October 14: v3.3.3.** Immich remains one of the most polished self-hosted replacements for cloud photo backup, with mobile upload, timeline browsing and album sharing. This October maintenance release is a reminder to keep deployments current, although this edition does not claim any specific new feature without verified upstream changelog details. For a Synology-backed photo library, evaluate storage layout and backup strategy before migration.

## Editorial notes

This edition intentionally favors apps that are useful on their own. The final five entries are updates to established projects, n8n is included as a labeled **source-available exception**; its licensing differs from conventional OSI open source. As always, check current licenses, architectures, container tags and backup procedures before deploying.
