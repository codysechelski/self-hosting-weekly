# Self-Hosting Weekly — November 13, 2026

**Edition #12 · 25 projects · 20 newly featured discoveries + 5 ongoing-project updates**

This edition is about **small services that replace recurring subscriptions**: notes, saved links, document tools, lightweight analytics, internal apps and useful automations. There is little reason to add another infrastructure dashboard when a one-purpose application can solve an actual daily problem.

**Three to try first:** BentoPDF for private PDF chores, Memos for frictionless capture, and ConvertX for local file conversion. **For more involved projects:** evaluate Listmonk, Windmill and NocoBase only when a specific recurring workflow justifies their extra maintenance.

**Research note (November 13, 2026):** These are *newly featured here*, not claims that all 20 launched this week. The GitHub repositories below were returned by repository searches filtered for activity after November 5, 2026. Repository activity alone does not prove a release occurred; the update section intentionally avoids unverified version claims. Verify licensing, current install instructions and changelogs before production use. No screenshots are embedded because upstream image URLs could not be verified reliably; guessed or hotlinked third-party images would risk broken assets.

## New & Interesting

### 1. Serviette — Searchable document library

**Project:** [Serviette](https://github.com/pathwaycom/serviette) · [Activity and releases](https://github.com/pathwaycom/serviette/releases)

Serviette is a no-code document-search and question-answering server built on Pathway, with a web interface and an API. It watches files for changes and keeps search indexes current; the default local embedding option and embedded DuckDB backend make it possible to start without a managed vector database. It is an exception to this newsletter's usual avoidance of AI-heavy tools because it solves a concrete knowledge-management problem, though it requires a free Pathway license key and optional generated answers can incur API charges. It does not currently provide built-in user accounts, so place it behind authentication if exposing it remotely.

### 2. Memos — Quick capture

**Project:** [Memos](https://github.com/usememos/memos) · [Activity and releases](https://github.com/usememos/memos/releases)

Memos is a compact, self-hosted capture tool for short notes, thoughts and lightweight personal journaling. It favors quick entry over elaborate databases or document hierarchies, making it a plausible replacement for a private microblog or simple cloud notes app. For a small home server, it is more approachable than a full collaboration suite.

### 3. Reactive Resume — Resume builder

**Project:** [Reactive Resume](https://github.com/reactive-resume/reactive-resume) · [Activity and releases](https://github.com/reactive-resume/reactive-resume/releases)

Reactive Resume provides an open-source résumé builder with templates and PDF export. Self-hosting can keep your career data in your own deployment rather than inside a subscription résumé service. Its editing experience is the reason to try it; check the current self-hosting instructions before relying on it for an important application.

### 4. TriliumNext Notes — Knowledge management

**Project:** [TriliumNext Notes](https://github.com/TriliumNext/Trilium) · [Activity and releases](https://github.com/TriliumNext/Trilium/releases)

TriliumNext is a hierarchical personal knowledge base with rich notes, relationships and extensive organization options. It is attractive when a flat folder of Markdown files is no longer sufficient, although its data model is less plain-text-native than Obsidian. This is a substantial application rather than a tiny capture utility, so evaluate backup and export carefully.

### 5. Glance — Personal dashboard

**Project:** [Glance](https://github.com/glanceapp/glance) · [Activity and releases](https://github.com/glanceapp/glance/releases)

Glance assembles feeds, bookmarks, calendars and other small widgets into a single self-hosted dashboard. It replaces a personal start-page subscription without becoming a full monitoring platform. A configuration-driven layout is especially useful on a Raspberry Pi or an existing reverse-proxy domain.

### 6. Karakeep — Bookmarks

**Project:** [Karakeep](https://github.com/karakeep-app/karakeep) · [Activity and releases](https://github.com/karakeep-app/karakeep/releases)

Karakeep collects bookmarks and saved pages into a searchable read-it-later library. It is a strong candidate for replacing a hosted bookmark manager, especially when browser capture and archiving matter more than social discovery. Review storage and optional AI features; the core idea does not require turning your library into an AI project.

### 7. Plausible Analytics — Analytics

**Project:** [Plausible Analytics](https://github.com/plausible/analytics) · [Activity and releases](https://github.com/plausible/analytics/releases)

Plausible offers privacy-conscious website analytics that can be deployed on your own infrastructure. It targets the everyday traffic and referral questions that otherwise send publishers toward hosted analytics subscriptions. Its operational footprint is larger than a simple static counter, so compare the self-hosted deployment with Umami before choosing.

### 8. ArchiveBox — Web archiving

**Project:** [ArchiveBox](https://github.com/ArchiveBox/ArchiveBox) · [Activity and releases](https://github.com/ArchiveBox/ArchiveBox/releases)

ArchiveBox preserves web pages and related content for long-term personal reference. Unlike a bookmark manager that only stores URLs, it aims to retain copies of material that may disappear or change. It makes a useful complement to a read-later workflow, though archival storage can grow quickly.

### 9. Listmonk — Newsletter

**Project:** [Listmonk](https://github.com/knadh/listmonk) · [Activity and releases](https://github.com/knadh/listmonk/releases)

Listmonk is a self-hosted mailing-list and newsletter manager with campaigns, subscribers and analytics. It can replace a paid newsletter platform for someone willing to manage email deliverability and compliance. Its database-backed deployment is reasonable for a home server, but sending reputation remains your responsibility.

### 10. NocoBase — Internal tools

**Project:** [NocoBase](https://github.com/nocobase/nocobase) · [Activity and releases](https://github.com/nocobase/nocobase/releases)

NocoBase is an extensible no-code platform for internal data apps and workflows. It is more flexible than a simple form builder, making it useful for small CRMs, inventory tracking or administrative portals. That flexibility brings complexity, so begin with a narrowly scoped workflow rather than treating it as a universal SaaS replacement.

### 11. Linkwarden — Shared bookmarks

**Project:** [Linkwarden](https://github.com/linkwarden/linkwarden) · [Activity and releases](https://github.com/linkwarden/linkwarden/releases)

Linkwarden combines bookmarks, collections and preserved web content in a team-friendly interface. It is worth comparing with Karakeep and ArchiveBox because all three approach saving the web differently. For a solo user, its collaboration features may be unnecessary; for a small group, they could replace a paid shared-link library.

### 12. ConvertX — File conversion

**Project:** [ConvertX](https://github.com/C4illin/ConvertX) · [Activity and releases](https://github.com/C4illin/ConvertX/releases)

ConvertX provides a self-hosted web interface for converting files between formats. It is the sort of narrow utility that can eliminate repeated uploads to random third-party conversion websites. Check which formats depend on installed conversion binaries and keep resource limits in mind for large files.

### 13. DocuSeal — Document signing

**Project:** [DocuSeal](https://github.com/docusealco/docuseal) · [Activity and releases](https://github.com/docusealco/docuseal/releases)

DocuSeal handles document preparation, forms and electronic signatures in a self-hostable application. It is a plausible alternative to paid signature workflows for low-volume internal use. Because signatures can carry legal and compliance requirements, evaluate audit trails and jurisdiction-specific needs rather than assuming feature parity with every commercial service.

### 14. Windmill — Workflow automation

**Project:** [Windmill](https://github.com/windmill-labs/windmill) · [Activity and releases](https://github.com/windmill-labs/windmill/releases)

Windmill turns scripts and workflows into scheduled jobs, internal apps and operator-facing interfaces. It is attractive for automating routine business tasks while keeping source code and execution under your control. Compared with Dagu, it offers a broader app-building surface but can be more involved to operate.

### 15. Maxun — Data extraction

**Project:** [Maxun](https://github.com/getmaxun/maxun) · [Activity and releases](https://github.com/getmaxun/maxun/releases)

Maxun focuses on extracting data from websites through browser-based automation. It can replace some recurring scraping and data-collection subscriptions when you have a well-defined source and permission to access it. Website changes and anti-bot measures remain operational risks, so treat it as a workflow tool rather than a guaranteed data feed.

### 16. La Suite Docs — Collaborative docs

**Project:** [La Suite Docs](https://github.com/suitenumerique/docs) · [Activity and releases](https://github.com/suitenumerique/docs/releases)

La Suite Docs is a collaborative document editor from the French public-sector open-source ecosystem. It is an interesting alternative to cloud document collaboration for teams that prioritize ownership and open deployment. Confirm the current production readiness and deployment prerequisites; this is not necessarily a drop-in replacement for an entire office suite.

### 17. PrivateBin — Encrypted pastes

**Project:** [PrivateBin](https://github.com/PrivateBin/PrivateBin) · [Activity and releases](https://github.com/PrivateBin/PrivateBin/releases)

PrivateBin is a minimalist encrypted paste-sharing application. It is useful for sending snippets without building an account-heavy collaboration system, and it can fit behind an existing reverse proxy. It is not a secrets manager: sharing links, expiration settings and the security of recipient devices still matter.

### 18. TagSpaces — File organization

**Project:** [TagSpaces](https://github.com/tagspaces/tagspaces) · [Activity and releases](https://github.com/tagspaces/tagspaces/releases)

TagSpaces organizes local files and notes with tagging and a visual interface. It is interesting for people who want document organization without locking content into a proprietary cloud database. Evaluate which sync and collaboration features are available in the open-source edition before choosing it over an existing NAS folder structure.

### 19. Piwigo — Photo galleries

**Project:** [Piwigo](https://github.com/Piwigo/Piwigo) · [Activity and releases](https://github.com/Piwigo/Piwigo/releases)

Piwigo is a mature, self-hosted photo gallery with albums, permissions and extensibility. It serves a different need from Immich: publishing and organizing curated galleries rather than primarily backing up a phone camera roll. That makes it useful for sharing collections without paying for a hosted photo portfolio.

### 20. BentoPDF — PDF utilities

**Project:** [BentoPDF](https://github.com/alam00000/bentopdf) · [Activity and releases](https://github.com/alam00000/bentopdf/releases)

BentoPDF brings everyday PDF operations into a browser-oriented open-source tool. Merging, splitting and editing PDFs are the kinds of occasional tasks that often push users toward subscription services or privacy-questionable upload sites. It is a particularly appealing small utility to keep available on a personal tools domain.

## Notable Updates

The following established projects showed repository activity during November 6–13. They are included as **projects to watch or review**, not as verified new feature-release announcements.

### 1. Stirling-PDF — PDF tools

**Project:** [Stirling-PDF](https://github.com/Stirling-Tools/Stirling-PDF) · [Release notes](https://github.com/Stirling-Tools/Stirling-PDF/releases)

Stirling-PDF remains one of the broadest self-hosted PDF toolkits, covering conversion, organization and editing workflows. The repository shows continued activity during this reporting window, though a specific November release is not independently verified here. Existing users should review upstream release notes and backups before upgrading; newcomers should compare its wider feature set with BentoPDF.

### 2. Gitea — Git hosting

**Project:** [Gitea](https://github.com/go-gitea/gitea) · [Release notes](https://github.com/go-gitea/gitea/releases)

Gitea continues to be actively developed and remains a practical GitHub alternative for private repositories, issues and code review. Its lightweight deployment model makes it more plausible on a small home server than a large DevOps suite. This is an activity watch rather than a claim of a particular November feature release.

### 3. Changedetection.io — Website monitoring

**Project:** [Changedetection.io](https://github.com/dgtlmoon/changedetection.io) · [Release notes](https://github.com/dgtlmoon/changedetection.io/releases)

Changedetection.io monitors web pages for changes and can notify you when important content moves. It can replace several small monitoring subscriptions, from product availability checks to documentation updates. Recent repository activity merits checking its changelog, but no specific version change is asserted in this edition.

### 4. Nextcloud — Cloud collaboration

**Project:** [Nextcloud](https://github.com/nextcloud/server) · [Release notes](https://github.com/nextcloud/server/releases)

Nextcloud remains a full-featured self-hosted file and collaboration platform, with ongoing repository development. It can replace multiple cloud subscriptions but demands considerably more maintenance than a focused file portal. If you already have Synology Drive, a new deployment only makes sense for specific collaboration features you actually need.

### 5. Gotify — Notifications

**Project:** [Gotify](https://github.com/gotify/server) · [Release notes](https://github.com/gotify/server/releases)

Gotify provides a straightforward self-hosted push-notification service for scripts and applications. It is a good fit for status changes, cron jobs and home-server alerts without routing everything through a commercial automation platform. The repository has recent activity, but check the upstream release page for exact upgrade notes before making changes.
